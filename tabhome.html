How to Start Creating and Sharing Your Timetables

1. Create Admin Account

2. Log In and Input Necessary Data
- N.B. Preview will be shown continuously after each data input.

- N.B. This pass string will be shared with whoever you want to look at the timetable.

4. Create Modify Key (Optional)
- N.B. This key will give access to selected public users or lecturers to adjust or cancel entries.
